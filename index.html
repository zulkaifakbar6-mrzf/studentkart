Product

Ye wo orders hain jo is browser se place hue (WhatsApp/Email ke saath bhi gaye hain). Emails zulkaifakbar6@gmail.com par aate hain.

Har product par hourly random sale lagti hai. Range set karein (default 13%–19%). Original price wahi rehti hai jo aap ne di — sale price usi se calculate hoti hai, is liye profit hamesha safe hai. 👍

Apna Supabase project connect karein. Database URL aur anon/publishable key (service key kabhi nahi!) paste karein. Table products aur setup SQL file supabase_setup.sql mein di gayi hai — pehle wo Supabase SQL Editor mein run karein. Writes (Push) ke liye neeche Supabase Auth mein sign-in zaroori hai — RLS is liye lagi hai ke koi random visitor products change na kar sake.

Supabase se products manage karne ka tarika:

1️⃣ supabase.com par project kholo → SQL Editor → supabase_setup.sql file ka pura SQL paste kar ke Run karo.
2️⃣ Project Settings → API → Project URL aur anon public key copy karo.
3️⃣ Is site ke Admin → 🗄️ Supabase tab mein paste kar ke Save & Test dabao.
4️⃣ Ab do tareeqay hain:
  • Push: site ke current products Supabase mein save ho jayenge.
  • Pull: Supabase ka data site par show hoga.
5️⃣ Baar baar edit karne ke liye best tareeqa: Supabase Table Editor mein products table kholo aur seedha edit karo (name, price, image URL, active) — changes turant website par aa jayenge.
6️⃣ Images ke liye Supabase Storage mein product-images bucket banao (SQL khud bana dega), photos upload karo aur unka public URL product ke img field mein paste karo.
7️⃣ Orders email par aate hain (FormSubmit activation zaroori hai — README dekho).

⚠️ Yaad rakho: anon key public hoti hai, is liye SQL mein RLS policies already laga di gayi hain — customers sirf active products dekh sakte hain, orders sirf insert kar sakte hain, kuch aur nahi.
